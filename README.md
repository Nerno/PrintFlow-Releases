# PrintFlow — раздача обновлений

Здесь лежат только выпуски PrintFlow. Кода программы тут нет.

PrintFlow — программа для печати комплектов проектной документации: собирает
разрозненные файлы в комплект, раскладывает по принтерам и отправляет в печать.

## Что в этом репозитории

| Файл | Что это |
|---|---|
| `latest.json` | Указатель: какая версия сейчас последняя и где её взять |
| Выпуски (Releases) | Установщики `PrintFlow-<версия>-setup.exe` |

Программа раз в сутки читает `latest.json`, и если там версия новее — предлагает
обновиться. Установщик она скачивает сама и перед запуском проверяет три вещи:
размер, отпечаток SHA-256 и цифровую подпись.

## Указатель

```json
{
  "version": "0.1.0-beta.11.51",
  "date": "2026-09-19",
  "url": "https://github.com/Nerno/PrintFlow-Releases/releases/download/v0.1.0-beta.11.51/PrintFlow-beta.11.51-setup.exe",
  "size": 51380224,
  "sha256": "…",
  "notes": "Что нового в этой версии."
}
```

## Почему репозиторий отдельный и публичный

Репозиторий с кодом закрытый. Чтобы программа могла читать указатель, ей нужен
был бы ключ доступа — а зашивать ключ в раздаваемую программу нельзя. Поэтому
раздача вынесена сюда: здесь нет ничего, что стоило бы прятать.

## Подпись

Установщики подписаны. Пока это самоподписанный сертификат, поэтому Windows
SmartScreen при скачивании предупреждает — это ожидаемо. Программа сверяет не
доверие Windows, а то, что подпись цела и ключ тот же, которым подписана уже
установленная копия.
